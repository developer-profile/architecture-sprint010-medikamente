# Оценка криптографической защиты данных в состоянии покоя и передачи

## I. Идентификация данных, подлежащих криптографической защите

### Классификация информационных активов:

I. Категоризация по типу и уровню конфиденциальности:
   i. Персональные идентификационные данные (PII): ФИО, контактная информация, паспортные данные
   ii. Медицинская информация: клинические диагнозы, результаты лабораторных исследований, электронные медицинские карты
   iii. Финансовые данные: платежные реквизиты, договорная документация
   iv. Аутентификационная информация: учетные записи пользователей, пароли, токены доступа к информационным системам
   v. Метаданные: временные метки записей, идентификаторы пациентов

II. Классификация по состоянию обработки данных:
   i. Данные в состоянии покоя: реляционные базы данных, файловые системы серверов, резервные копии
   ii. Данные в процессе передачи: API-запросы, межсервисные коммуникации, загрузка в облачную инфраструктуру
   iii. Данные в процессе обработки: оперативная память приложений, кэш-системы

## II. Реализация базовых механизмов криптографической защиты

### Криптографические методы защиты:

|Тип данных|Метод защиты|Инструменты|
|--|---|---|
|Персональные данные|AES-256, TDE (Transparent Data Encryption)|PostgreSQL (pg_crypto), BitLocker, VeraCrypt|
|Передаваемые данные|TLS 1.3, HTTPS, VPN|Nginx (SSL), OpenVPN, WireGuard|
|Данные в процессе обработки|Контейнеры с изоляцией памяти|Intel SGX, AWS Nitro Enclaves|

### Системы контроля доступа:

I. Ролевое разграничение доступа (RBAC):
   i. Определение ролей: медицинский персонал, кассовые операторы, системные администраторы

II. Атрибутное управление доступом (ABAC):
   i. Контроль доступа на основе атрибутов субъекта (например, "доступ исключительно к закрепленным пациентам")
   ii. Технологические решения: Keycloak (IAM), HashiCorp Vault (управление секретами)

### Методы анонимизации и маскирования данных:

I. Динамическое маскирование данных:
   i. Замещение персональных идентификаторов системными ID в BI-отчетах

II. Токенизация конфиденциальной информации:
   i. Замещение чувствительных данных криптографическими токенами (платежные реквизиты)
   ii. Инструментальные средства: Apache Atlas (Data Lineage), Protegrity (маскирование данных)

### Системы мониторинга и аудита:

I. SIEM-системы для анализа журналов событий и генерации алертов:
   i. Технологические решения: Elastic SIEM

II. Системы предотвращения утечек данных (DLP):
   i. Инструментальные средства: Symantec DLP

III. Журналирование операций с данными:
   i. Технологические решения: PostgreSQL Audit Extension

## III. Автоматизированные механизмы контроля безопасности

### Политики информационной безопасности:

I. Автоматическая блокировка при множественных неуспешных попытках аутентификации:
   i. Технологические решения: Fail2Ban

II. Сканирование уязвимостей информационной инфраструктуры:
   i. Инструментальные средства: OpenVAS, Nessus

III. Верификация конфигураций серверного оборудования

### Интеграция с процессами непрерывной интеграции и развертывания (CI/CD):

I. Статический анализ кода на предмет уязвимостей:
   i. Технологические решения: SonarQube, GitGuardian

II. Тестирование соответствия требованиям GDPR/ФЗ-152:
   i. Инструментальные средства: OWASP ZAP

## IV. Реестр средств защиты информационных активов

| Данные                     | В чём необходимость защиты                                            | Инструменты защиты                                                      |
|----------------------------|-----------------------------------------------------------------------|-------------------------------------------------------------------------|
| **PII (Персональные данные)** | Защита от утечки персональных данных пациентов (ФЗ-152, GDPR)      | HashiCorp Vault, PostgreSQL pg_crypto, Dynamic Masking в BI             |
| **Медицинские записи**       | Конфиденциальность диагнозов, результатов анализов                  | AES-256 шифрование (GPG), DLP-системы, Access Control (RBAC)            |
| **Финансовые транзакции**    | Защита платёжных реквизитов, предотвращение мошенничества           | PCI DSS-совместимые решения, Tokenization, HSM                          |
| **Учётные данные сотрудников** | Предотвращение несанкционированного доступа к системам            | MFA (YubiKey, Google Authenticator), Keycloak IAM                       |
| **API-запросы**             | Защита данных при передаче между сервисами                           | TLS 1.3, API Gateway с авторизацией                                     |
| **Бэкапы**                  | Защита резервных копий от утери/кражи                                | BorgBackup с шифрованием, изолированное хранилище (Air-Gapped)          |
| **Журналы аудита**          | Обеспечение целостности логов для расследований                      | SIEM (Wazuh, Splunk), Blockchain для логов (IBM Blockchain Platform)    |
| **Данные в Kubernetes**     | Защита конфигураций и секретов в облачной среде                      | Sealed Secrets, KMS (AWS KMS)                          |
| **Мобильные данные**        | Защита данных в мобильном приложении                                 | App Shield (DexGuard), Certificate Pinning                              |
| **Электронная почта**       | Предотвращение утечки конфиденциальной информации через email        | S/MIME шифрование, ProtonMail, Exchange Online Protection               |
